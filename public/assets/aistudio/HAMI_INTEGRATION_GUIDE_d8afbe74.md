# راهنمای ادغام مستقیم ماژول GPS و ناوگان در نرم‌افزار «حامی» (بدون نیاز به کدنویسی مجدد)

این راهنما توضیح می‌دهد که چگونه همین فایل‌ها و کدهای پیاده‌سازی‌شده را بدون نیاز به کدنویسی مجدد، مستقیماً وارد نرم‌افزار اصلی حامی کنید.

---

## ۱. ساختار فایل‌های آماده جهت کپی در پروژه حامی

تمام فایل‌های این بخش در یک بسته کامل و خودکفا (Self-Contained) گردآوری شده‌اند:

```text
hami-project/
├── src/
│   ├── modules/
│   │   ├── HamiFleetModule.tsx      <-- کامپوننت مادر (شامل رفرش، پولینگ، مدیریت استیت و ارتباط API)
│   │   ├── index.ts                 <-- نقطه ورود و خروجی ماژول
│   │   └── types.ts                 <-- کلیه تایپ‌ها و اینترفیس‌های TypeScript
│   └── components/
│       ├── FleetMapModule.tsx       <-- نقشه تعاملی، دراورهای مأموریت، بارنامه، سوخت و سرویس
│       ├── MonthlyFuelTrendWidget.tsx <-- ویجت مینیمال Recharts روند مصرف سوخت ماهانه
│       └── index.ts
├── fleet-missions.json              <-- دیتابیس بارنامه‌ها و مأموریت‌های حامی
├── fleet-fuel-logs.json             <-- دیتابیس سوابق و مراحل سوخت‌گیری
├── fleet-maintenance-rules.json     <-- قوانین سرویس دوره‌ای و لیمیت‌های کیلومتری/روزانه
├── fleet-maintenance-logs.json      <-- سوابق تعویض روغن و سرویس‌ها
└── fleet-geofences.json             <-- محدوده‌های جغرافیایی و پایانه‌ها
```

## ۲. استفاده در فرانت‌اند حامی (فقط ۲ خط کد!)

در هر صفحه، روت یا تبی از برنامه حامی (مثلاً `/fleet` یا `/tracking` یا منوی «رهگیری ناوگان و بارنامه‌ها»)، کافی است کامپوننت را صدا بزنید:

```tsx
import { HamiFleetModule } from './modules';

export default function FleetPage() {
  return (
    <div className="w-full h-screen">
      {/* ماژول خودکفا: کل نقشه، منوها، بارنامه‌ها، سوخت و ردیابی را به صورت کامل لود می‌کند */}
      <HamiFleetModule />
    </div>
  );
}
```

> **نکته:** اگر روت‌های بک‌اند شما روی پیشوند متفاوتی قرار دارند (مثلاً `/api/v1`)، می‌توانید به راحتی پراپ ارسال کنید:  
> `<HamiFleetModule apiBaseUrl="/api/v1" />`

## ۳. استفاده در بک‌اند حامی (اتصال APIها)

اندپوینت‌های زیر در فایل `server.ts` به صورت کاملاً ماژولار پیاده‌سازی شده‌اند و آماده ادغام در فایل سرور حامی (Express / Node.js) هستند:

1. **`GET /api/vehicles`**: موقعیت‌های زنده GPS، وضعیت آنلاین/آفلاین، پلاک، و بارنامه فعال خودرو.
2. **`GET /api/missions`** و **`POST /api/missions`**: دریافت و صدور بارنامه‌های ترابری حامی.
3. **`PATCH /api/missions/:id/status`**: تغییر وضعیت سفر خودرو بین ۴ حالت (`loading`، `in_transit`، `unloaded`، `completed`).
4. **`POST /api/drivers/sync`**: همگام‌سازی فوری راننده جدید با کد دستگاه در حامی.
5. **`GET /api/fuel/analytics`** و **`POST /api/fuel/logs`**: تحلیل پیمایش بعد از آخرین سوخت‌گیری و ثبت مراحل سوخت.
6. **`GET /api/playback`**: بازپخش تاریخچه حرکت خودروها.

## ۴. قابلیت‌هایی که بلافاصله و خودکار فعال می‌شوند:
- ✅ **حلقه رنگی بارنامه روی آیکون خودرو**: در مسیر (سبز زمردی پالس‌دار)، در حال بارگیری (کهربایی)، تخلیه شد (آبی).
- ✅ **درصد زنده پیشرفت سفر روی آیکون**: نمایش بج عددی (مثلاً `۶۸٪`) روی نشانگر ماشین در نقشه.
- ✅ **تخمین دقیق زمان رسیدن (ETA)**: بر مبنای سرعت زنده GPS و مسافت مانده تا مقصد بارنامه.
- ✅ **تحلیل مراحل و مصرف سوخت**: پیمایش از آخرین سوخت‌گیری، شعاع پیمایش باقیمانده باک، و ویجت Recharts روند ماهانه.
- ✅ **حالت تمام‌صفحه (Fullscreen)** و طراحی ضد شلوغی و مینیمال.
